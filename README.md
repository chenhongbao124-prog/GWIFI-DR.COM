# Gwifi 校园网认证工具

这是一个面向 OpenWrt / LuCI 的校园网认证插件源码整理版，围绕 Dr.COM 风格的认证流程提供线路管理、状态查看、NAS 检查、保活和 TTL 管理等功能。校园认证系统差异很大；即使都使用 Dr.COM，也需要按实际门户参数适配，不能保证通用。

当前版本仍在实机验证阶段。NAS 自动迁移、多网口组合以及 Mihomo / Clash 联动尚未完成广泛验证。请先备份路由器配置，用单条线路测试，再启用多拨或自动功能。

## 仓库内容

- `source/`：插件运行文件，按它们在路由器上的安装路径排列。
- `install-upgrade.sh`：升级安装脚本，要求把 `source/` 中的文件先放到路由器 `/tmp/gwifi-stage/`。
- `config.example`：空白配置示例，不含校园服务器、NAS、AES 密钥或个人账号。

公开仓库不附带针对某所学校生成的安装包。学校共用的服务器地址、NAS 名称和 AES 密钥也可能属于敏感配置，使用者应从自己的认证门户或网络管理员处获取。

## 使用前

需要支持 LuCI 的 OpenWrt 系统，并安装脚本使用的依赖。不同发行版的包管理器和依赖名称可能不同；高版本 OpenWrt 常使用 `apk`，较旧版本常使用 `opkg`。在 LuCI 的环境检测页检查缺少的依赖。

第一次使用，请在 LuCI 的认证设置里填写认证服务器、NAS 名称、AES 密钥、账号和密码，并核对实际上网接口。不要直接启用示例配置中的线路。

## 手动安装源码

先将 `source/` 中的目录和文件按原有结构上传到路由器的 `/tmp/gwifi-stage/`，并把本仓库的 `install-upgrade.sh` 上传到同一目录。然后通过 SSH 执行：

```sh
cd /tmp/gwifi-stage
sh install-upgrade.sh
```

安装脚本会校验 `SHA256SUMS`、备份现有程序并在检查失败时恢复程序文件。安装前仍建议备份路由器配置。该仓库面向源码查看和自行适配，不提供无需配置即可使用的学校专用安装包。

## 安全和限制

- 不要提交包含真实账号、密码、认证日志、会话地址或路由器配置的文件。
- 不要把个人版安装包放入公开仓库。
- 参考 Mihomo YAML 不会自动应用到路由器，本插件也不包含代理核心或订阅。
- 认证结果取决于学校认证平台的策略、设备绑定和接口环境。
